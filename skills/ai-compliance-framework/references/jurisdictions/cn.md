# China — AI Regulations

> **Status:** Enforced — multiple binding regulations in effect
> **Binding:** YES — multiple legally binding regulations
> **Confidence:** HIGH for existence and general scope; MEDIUM for exact article text (translations may vary)
> **Sources:**
>
> - Interim Measures for the Management of Generative AI Services (2023)
> - Provisions on the Management of Algorithmic Recommendations (2022)
> - Provisions on the Management of Deep Synthesis (Deepfakes) (2023)
> - AI Safety Governance Framework (TC260, 2024)

## Regulatory Landscape

China has taken a use-case-specific legislative approach rather than a single comprehensive law:

| Regulation | Effective Date | Scope |
| ----------- | --------------- | ------- |
| Algorithm Recommendation Provisions | 1 Mar 2022 | Recommendation algorithms |
| Deep Synthesis Provisions | 10 Jan 2023 | Deepfakes, synthetic media |
| Generative AI Measures | 15 Aug 2023 | GenAI services offered to public in China |
| AI Safety Governance Framework | Sep 2024 | Cross-cutting safety guidance (TC260) |

## Generative AI Measures (Interim, 2023)

**Applies to:** Organisations providing generative AI services to the public within China.

### Key Requirements

**Content Safety:**

- GenAI output must adhere to "core socialist values"
- Must not generate content that incites subversion, terrorism, ethnic hatred, discrimination, violence, or obscenity
- Must not generate false/harmful information
- Content safety measures must be implemented before service launch

**Data & Training:**

- Training data must be obtained through lawful means
- Training data must not infringe intellectual property rights
- Personal information in training data requires consent
- Data labelling must be accurate and conform to relevant standards
- Measures to improve quality, accuracy, objectivity, and diversity of training data

**Transparency:**

- GenAI-generated content must be clearly labelled/watermarked
- Users must be informed about capabilities, limitations, and risks
- Service providers must provide real-name verification for users

**User Rights:**

- Users can request deletion of personal information
- Complaint and feedback mechanisms required
- Provider must handle user complaints within specified timeframes

**Filing Requirements:**

- Service providers must file algorithm details with the Cyberspace Administration of China (CAC)
- Security assessments required before public launch

### Generative AI Measures — Checklist

```text
[ ] Content safety filters implemented and tested
[ ] Training data provenance documented
[ ] IP rights clearance for training data
[ ] Consent obtained for personal data in training
[ ] AI-generated content labelled/watermarked
[ ] User verification mechanism in place
[ ] Complaint handling process established
[ ] Algorithm filing with CAC completed (if serving China)
[ ] Security assessment completed
```

## Algorithm Recommendation Provisions (2022)

**Applies to:** Services using algorithm-based recommendations.

**Key Requirements:**

- Users must be able to opt out of personalised recommendations
- Algorithm must not create "information cocoons" or manipulate user behaviour
- Price discrimination based on user profiling prohibited
- Special protections for minors and elderly
- Algorithm filing and registration with CAC

## Deep Synthesis Provisions (2023)

**Applies to:** Deep synthesis technology (deepfakes, AI-generated/edited media).

**Key Requirements:**

- All deep synthesis content must be labelled
- Providers must implement anti-misuse mechanisms
- Real-name verification for users creating deep synthesis content
- Prohibited uses: fake news, defamation, impersonation
- Technical measures to prevent removal of labels/watermarks

## AI Safety Governance Framework (TC260, 2024)

**A cross-cutting guidance document covering:**

- Model development safety (training data, model architecture)
- Deployment safety (testing, red-teaming, monitoring)
- Usage safety (misuse prevention, user safety)
- Data safety (personal data, sensitive data handling)

> **Confidence:** MEDIUM — TC260 framework is guidance-level, not directly enforceable, but signals regulatory direction.

### General Compliance Checklist

```text
[ ] Content moderation system for all outputs
[ ] Watermarking/labelling for AI-generated content
[ ] Training data lawfulness verified
[ ] User opt-out mechanisms for personalisation
[ ] Minor protection measures if applicable
[ ] Algorithm registration completed (if serving China)
[ ] Security assessment filed (if serving China)
[ ] Real-name verification system (if serving China)
```
